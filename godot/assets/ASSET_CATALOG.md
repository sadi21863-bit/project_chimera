# Project Chimera Asset Catalog

## Overview
Comprehensive catalog of art assets, sprites, maps, models, and resources from various game engines that can be imported into Godot 4.7.

## Current Asset Structure
```
godot/assets/
├── audio/          # Sound effects and music
├── buildings/      # Building exteriors
├── characters/     # Character sprites (Sam, Riley, Morgan)
├── furniture/      # Living room, bedroom, bathroom furniture
├── tiles/          # Floor tiles
├── tilesets/       # Pipoya tilesets
└── ui/             # User interface elements
```

## Import Formats Supported by Godot
- **3D**: GLTF/GLB (preferred), FBX, OBJ, Blend (requires Blender)
- **2D**: PNG, JPG, WebP
- **Audio**: WAV, OGG, MP3
- **Fonts**: TTF, OTF, WOFF

## Integration Guidelines

### Directory Structure
```
godot/assets/
├── 3d/
│   ├── detective_office/
│   ├── crime_scene/
│   ├── dormitory/
│   └── furniture/
├── 2d/
│   ├── characters/
│   ├── detective_items/
│   ├── interior/
│   └── ui/
├── audio/
│   ├── music/
│   ├── sfx/
│   └── ambience/
├── textures/
│   ├── floors/
│   ├── walls/
│   └── props/
└── fonts/
```

### Import Settings
- **3D Models**: Import as Scene, generate meshes, generate materials
- **Textures**: Import as Texture2D, filter nearest for pixel art, filter linear for 3D
- **Audio**: Import as AudioStream, compress mode: Disabled for SFX, RAM for music
- **Fonts**: Import as FontFile, antialiasing: None for pixel fonts

### Naming Conventions
- Use snake_case for all asset files
- Prefix with category: `detective_office_desk_01.glb`
- Use descriptive names: `evidence_marker_red_01.png`
