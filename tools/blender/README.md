# Project Chimera Blender Asset Pack

These are low-poly, orthographic-friendly dorm props designed for the game's existing isometric presentation.

`generate_chimera_assets.py` is the source-of-truth Blender generator. Open it in Blender 4.x and run it to regenerate the GLB files under `godot/assets/3d/dorm/`.

Included assets:
- bed
- desk
- chair
- bookshelf
- locker
- lamp
- trash_bin
- evidence_board
- suitcase
- security_camera

The checked-in GLBs are lightweight engine-ready fallbacks. The Blender script can regenerate them with editable materials and geometry.
